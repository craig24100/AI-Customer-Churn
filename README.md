# AI Customer Churn Prediction

A full-stack machine learning application that predicts whether a bank customer is likely to churn.

## Features

- Customer churn prediction
- Random Forest machine learning model
- FastAPI REST API
- React frontend
- Real-time predictions

## Tech Stack

- Python
- Pandas
- Scikit-learn
- FastAPI
- React
- Axios

## Model Performance

- Accuracy: 86%

## Run Backend

```bash
cd backend
source .venv/bin/activate
uvicorn app:app --reload
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```
